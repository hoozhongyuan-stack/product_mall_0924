# 进货与配送优化：HTML 方案与验收说明

状态：2026-10-12，本轮七个模块的本地 HTML 交互稿已完成，供确认操作流程；用户确认 HTML 后才进入正式开发。已确认费用承担口径：经营包邮由前置仓承担，平台活动包邮由平台承担。

入口：[打开交互稿](index.html)。通过本地静态服务打开后，使用顶部模块标签切换；“重置演示”恢复初始示例。所有保存只在当前页面内有效，刷新即恢复，不连接 UAT、真实地图、库存或支付，不创建真实订单，不代表生产问题已修复或发布。

## 评审范围与操作步骤

| 模块 | 演示操作 | 确认重点 |
| --- | --- | --- |
| 进货数量 | 打开规格抽屉，手输数量或点击加减；体验演示键盘，滚动规格列表，点击“确认数量”；关闭抽屉可放弃未确认修改。 | 数量支持 0–999 整数，0 表示未选；未配置进货价的规格标注“暂不可进货”；列表独立滚动，确认按钮固定；确认后汇总同步更新。 |
| 付款凭证 | 选择“首次上传失败，可重试”，使用示例图片，查看失败提示，再“重试上传”，上传完成后点击“提交凭证，等待平台核款”。也可体验取消、权限拒绝和临时切后台示意。 | 选择、上传、提交分别反馈；上传完成仍待提交，提交后待平台核款；本地选图仅用于页面预览。 |
| 首页体验 | 在前置仓商城与餐饮桌码商城间切换；选择慢网络或加载失败，再重试；点击手机导航体验返回首页。 | 首页容器直接展示当前已发布微页面；加载时中性骨架，失败可重试；餐饮店与桌号固定。其他导航页为示意。 |
| 餐饮地图 | “地图选择位置”→搜索或选择示例 POI／地图点→“使用此位置”→“保存餐饮店”；查看后台回读区及手机预览。 | 使用位置后仍需保存资料；地址改变后需重新确认位置；沿用前置仓选点操作，餐饮保持指定履约仓。 |
| 业务编号 | 选择业务类型、北京时间创建时间与当日该类型流水，生成并查看手机侧示例编号。 | 类型码 + 精确到秒的创建时间 + 六位流水的可读形式；内部标识、支付流水独立。服务端并发、唯一性和幂等实现属于后续开发。 |
| 快递运费 | 查询、筛选、勾选、批量启停；新建或编辑模板，填写计费、地区、商品分类与门槛后保存；重新编辑回读；选择模板试算，查看手机运费明细及订单预览。 | 按单、按件、按重量可配置；配送地区与禁配地区明确；费用支持分；后台配置与手机试算联动。 |
| 配送围栏 | 新建圆形／多边形／排除区；圆形点选圆心，多边形至少点选 3 个顶点并完成绘制后保存；编辑费用、时段、起送与包邮门槛；地图选收货点试算。 | 排除区优先；配送区按优先级命中一条；未达到起送、范围外、排除区及非配送时段阻止订单预览；收费方式互斥。 |

快递模板与围栏均沿用已有后台的检索、列表、勾选、批量操作和弹窗编辑方式。订单预览保留本次示例报价，之后修改配置不改变已生成的本地预览金额。

## 费用示例与口径

以下是可在后台修改的演示值，确认配置流程不等于将这些数值定为生产规则。

| 示例 | 初始配置 | 试算示例 |
| --- | --- | --- |
| 按重量快递 | 首重 1000g／¥8，续重每 1000g／¥2，满 ¥199 包邮。 | 2300g、门槛商品金额 ¥128：续重向上计 2 段，顾客运费 ¥12；同重量达 ¥199，顾客运费为 0，示例成本 ¥12 由前置仓承担。 |
| 圆形配送区 | 半径 1.8km，固定费 ¥6，起送 ¥39，满 ¥99 包邮，配送 09:00–23:00。 | 圈内、配送时段内、商品金额 ¥68：顾客运费 ¥6；达 ¥99 时经营包邮，示例成本 ¥6 由前置仓承担。 |
| 多边形配送区 | 3km 内 ¥6，续每 1km／¥2；初始起送 ¥39、满 ¥99 包邮，配送 09:00–23:00。 | 命中区域、时段内、商品金额 ¥68、直线距离 4.2km：续距离向上计 2 段，顾客运费 ¥10。 |

报价及门槛金额采用**优惠券抵扣后、积分抵扣前的商品金额**，不含运费。平台活动包邮命中时，顾客运费为 0，由平台承担示例配送成本；经营包邮由前置仓承担。顾客免运费不表示配送成本消失。

原型里的“配送成本／前置仓承担／平台承担”只用于解释费用归属，数值以计费配置作示例，不接入真实成本或结算账本，不修改正式利润分成与结算公式。

## 视觉一致性与原型简化

这是 `store-mini-unification` 既有操作界面的延伸。源码与评审截图保持暗红主操作（当前主色 `#a92030`，后台组件 `#a32c3b`）、白色面板、浅灰背景和系统中文字体；标题、表单、列表、状态标签、弹窗与手机按钮保持同类操作的一致表达。桌面采用配置与手机预览并排，窄屏上下排列；本轮不另建视觉世界，不修改项目 DESIGN 或 impeccable 设计产物。

地图是本地 SVG 示意：100 × 100 平面坐标，横向 6km，固定仓库点位于中心，按平面距离演示围栏命中与直线距离。示例 POI、经纬度和地址用于确认选点流程，不能作为真实地理服务或配送路径依据。

快递地区当前以文本输入演示，试算选择单个模板。正式省／市／区选择、真实地址映射和多模板合并计费由后续开发落实；本次确认的是配置流程，这些简化不作为生产业务规则。
