# 订单履约治理交互稿

## Platform
web，独立 HTML 评审原型。

## Users and purpose
平台运营管理快递、授权虚拟核销和资金售后；前置仓员工执行本仓配送、自提和授权虚拟核销；顾客查看对应订单进度、凭证和售后。用户已认可履约治理方案，并明确要求三端 HTML 评审后再开发。

## Confirmed boundaries
实物配送到家和自提由前置仓履约、扣前置仓库存；快递由平台后台发货、扣平台总仓库存。虚拟商品支持仅平台、指定前置仓、平台加指定前置仓，分享同一份剩余权益。商品配置变更不修改已成交核销范围。付款扣库，交付不重复扣库；售后冻结数量不可继续履约。

## Review artifact
三端共享一份内存模拟数据，刷新恢复初始状态。普通、餐饮、积分、混合及异常示例只用于评审。未连接后端、UAT、真实支付、短信或地图。采购和仓间调拨不属于本次销售订单原型。

## Existing authority
继承工作区高保真视觉样板和门店模块原型的视觉体系；本地说明不替代正式需求和接口契约。本次不修改业务实现或发布。
