# 三端履约评审表面

模式：Operate。精确范围扩展现有商城；用户已经确认方案、角色与 HTML 技术形式。

THESIS：让评审者在同一笔模拟订单上切换角色，明确谁可以交付、从哪里扣库存、权益还剩多少。
OWN-WORLD：继承品牌红 #a3202b、深红 #801b24、正文 #20252a、白色工作区和 #f4f5f5 页面底；系统中文字体、紧凑表格、描边图标、明确文字状态。
STORY：平台统一订单查看责任归属；前置仓中心处理本仓任务；顾客详情查看交付或核销结果。配置核销范围与创建演示新单检验成交快照。
FIRST VIEWPORT：平台初始展示订单表格和筛选；手机端显示页面选择器、居中设备和评审说明。移动宽度优先显示可操作页面，说明随后。
FORM：原生 HTML/CSS/ES modules；生成可直接打开的独立 HTML，无新增生产依赖。继承已确定的视觉世界，不进行概念或品牌重设。
FINISH：完成状态测试、真实本地浏览器交互、1440/390/320宽度检查和独立审阅；这些证据仅属于原型。
