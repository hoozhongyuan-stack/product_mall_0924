# 店铺与小程序统一优化：实施与验收记录

2026-10-12，用户确认 [最终 HTML](prototypes/store-mini-unification/index.html) 并授权正式开发、浏览器验证、提交、推送及 UAT 部署。业务规则仍以项目需求真源和 `contract-v1.md` 为准。

## 本次范围

1. 首页装修与微页面合并管理，由唯一首页关联指向已发布页面。原 HOME 页面及其不可变发布历史保留；草稿编辑与线上发布分开。
2. 底部导航支持 1–5 项、排序、自定义名称、独立的未选中/选中图标及受控站内链接：当前首页、微页面、分类、购物车、我的。保存草稿允许配置尚未发布的微页面；发布必须通过目标和素材校验。
3. 分类页一级图标固定小正方形、单行横向滑动；左侧二级列表，右侧当前二级 3:1 横幅与商品。使用轻量图片并保留原图回退，切换分类后可以恢复暂时失败的图片。
4. 分类、购物车和我的删除重复正文标题，保留原生居中标题和必要操作。首页共用店标、店名、切换及营业时间布局；餐饮固定店铺和餐桌。
5. 确认订单、订单详情、用户/前置仓/联盟中心共用视觉规范，保留身份、权限、支付截止时间、付款说明、核销凭证和售后等必要事实。

商品继续按当前店铺销售授权与履约仓过滤，餐饮取餐厅名单交集；不改变库存、计价、运费、支付、采购、分润、结算和售后规则。购物车继续按店铺及餐饮场景隔离。原型新增的示例分类不会写入 UAT。

## 兼容与发布边界

- 首页使用独立关联及修订号，迁移初始关联原 HOME；切换只接受已发布内容，并要求当前首页关联及目标发布修订一致。
- 新导航结构使用 `schemaVersion:2`，新客户端通过 `navigationVersion=2` 读取目标和双图标；旧客户端继续收到兼容四项导航。后台与 API 部署不代表已安装的小程序自动更新。
- 本次 UAT 部署包括正式代码、迁移和不可变小程序源码同步；微信开发版本上传、提审、公开发布和真机验收分别记录，不能用浏览器或静态编译替代。
